✅ To-Do List – React App

This is a simple, interactive To-Do List application built using **React** and **Tailwind CSS**. It runs in the browser and helps users manage daily tasks efficiently. This project demonstrates core frontend development concepts like component-based architecture, state management, conditional rendering, and responsive UI design.

🔧 Features

- ➕ Add new tasks with a click
- ✅ Mark tasks as completed
- 🗑️ Delete individual tasks
- ✍️ Edit tasks (optional enhancement)
- 📦 Optional: Store tasks in local storage
- 📱 Responsive design for mobile and desktop

💡 What You’ll Learn

- Creating and composing React components
- Managing local state using `useState`
- Handling events (clicks, form submissions)
- Styling with Tailwind CSS
- Conditionally rendering components
- Building responsive and dynamic UIs

🚀 How to Run

Make sure **Node.js** and **npm** are installed on your system.
